1. install nodejs from https://nodejs.org/en/download/
2. verify installation by running `node -v` and `npm -v` in the command prompt
3. npm install create-react-app -g
npm - node package manager
npx - Node package runner / execute packages

create-react-app - a tool to create a new React application with a default configuration
4. create a new React application using `npx create-react-app my-app`

   npx create-react-app appdemo

5. create a folder for your React application appdemo
   - This will create a new folder named `appdemo` with all the necessary files and dependencies for a React application.`
